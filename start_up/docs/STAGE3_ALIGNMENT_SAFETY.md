# 配准关系确认、自由空间验证与自动恢复

`partial` 与 `partial_contour` 共享本流程。EHPR 检索和鲁棒精配准产生候选；候选通过几何检查并不直接发布融合。`legacy`、`enhanced` 保持原有流程。

## 首次融合

默认需要两组独立观测支持同一 `T_UGVmap_UAVmap`。独立性在各机器人自身地图中判断，不读取 Gazebo 真值，也不要求两机同时运动。

新的一组观测至少有一端同时满足：与已经计票的该端扫描窗口不重叠；实际扫描原点相距至少 0.5 m；按 0.5 m 体素统计的非地面结构中，至少 10% 未被该端已计票观测包含。比较对象为该假设的全部已计票观测，不是只与最近一帧比较。

相同输入、相同历史窗口、不同朝向检索、不同匹配半径及静止重复扫描不会增加票数。仅旋转 360° 激光雷达而未带来位置与结构变化也不会增加票数。两机停止且证据不足时，状态保持 `waiting_confirmation`，不会用等待时间替代证据。

每个关系假设最多保留 16 组候选观测，从中寻找满足条件且通过固定关系复验的独立组合。池中未选中的观测不计票；最早候选不会锁定确认起点。因此，即使第一组覆盖较广、无法与后续某帧组成独立证据，后续两组仍可完成确认。每次最多复验 32 个组合，避免历史重试占满工作队列。

候选地图关系在 0.25 m / 3° 内聚为一簇。选取支持观测中质量最高的真实估计，固定这个关系，重新验证所有支持观测的几何和可见性；不对多个解做平均。竞争关系仍能解释支持观测时继续等待。只有一个候选簇不再以 `score_margin=1` 假装已经验证唯一性。

## 双向单帧自由空间

累计近期云继续用于几何配准，射线验证只使用 `latest_scan` 的真实返回点和 `recent_center_local` 的实际扫描原点。缺少单帧附件的旧输入可以提供几何候选，但不能单独建立可信关系。

同时检查 UGV 点是否提前占据 UAV 的自由空间，以及反方向。角容差 0.5°、深度容差 0.75 m；每个角度单元保留真实最近返回，每条目标方向最多计一次。没有可比较返回的未知方向不当成自由空间。

每方向至少比较 50 个独立方向，其中至少 20 个包含非地面结构。总冲突率和非地面冲突率都不得超过 5%，避免大量地面点稀释虚假墙体。地面高度来自自身已有平面估计，非地面起点为地面以上 0.4 m。证据不足与观察到矛盾分别记录，前者不确认也不触发撤销。

## 已确认关系与恢复

小幅更新必须保持在固定确认锚点的 0.25 m / 3° 范围内，并在原确认观测上复验，防止连续小更新累积漂移。超出范围的候选进入新的待验证假设，不会单纯因为偏离旧关系而丢弃。

节点持续检查两端最新同步扫描。扫描时间差不超过 0.1 s、各自年龄不超过 1 s；两次有效检查至少相隔 0.5 s。两组不同扫描连续显示可靠冲突后，关系撤销，进入 `relocalizing`，所有融合显示话题发布空云。

撤销仅清除跨机器人关系及确认依据；双方原始累计地图、历史窗口和描述子保留。重新定位需要三组独立观测。新旧关系都能解释证据时不强行切换；若旧关系在至少两组支持观测上验证失败，而新关系通过全部三组，则允许大幅纠正。地图从双方各自原始缓存重新投影，不对旧融合结果再做变换。

session/epoch 改变与时钟回退沿用已有隔离策略。缓存热恢复只恢复双方自有数据，等待当前两端 epoch 后重新验证关系，不恢复旧的跨机器人信任。

## 接口和参数

ROS 消息格式不变。`MapAlignment.valid` 只表示已确认关系；`/stage3/status` 的 `alignment_state` 为 `waiting_confirmation`、`confirmed` 或 `relocalizing`。状态、事件和匹配 YAML 记录独立观测数、双向总/非地面射线统计、扫描时间戳、确认等待时间及撤销原因。

| 参数 | 默认值 |
|---|---:|
| `alignment_initial_observations` | 2 |
| `alignment_recovery_observations` | 3 |
| `alignment_baseline_m` | 0.5 |
| `alignment_structure_novelty` | 0.10 |
| `visibility_angle_deg` | 0.5 |
| `visibility_depth_m` | 0.75 |
| `visibility_max_conflict` | 0.05 |
| `visibility_min_rays` | 50 |
| `visibility_min_structure_rays` | 20 |

接受结果下的 `confirmation/` 保存各支持观测的完整云、近期云、原始单帧与坐标元数据。`stage3_verify_results.py` 会独立重算双向射线、扫描原点、独立性及最终地图变换，随后检查融合点和颜色。旧版结果文件仍按其原版本规则校验。

旧正例缺少扫描附件时，使用 `tests/extract_matching_scans.py` 从原 rosbag 按精确时间戳恢复自身注册点云。工具不读取跨机器人真值。不要把累计点云复制成 `latest_scan` 来补齐缺失证据。
